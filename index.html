    For agents & other agentic websites

    This site is itself callable. A conforming browser runtime on another origin can fetch agent-manifest.json, resolve the open_api_scout network, and run it locally on the caller's own key. The published definition is data-only — no code, no credentials, no server. See llms.txt for a plain-text map, and .well-known/agent-card.json for a discovery card.

    Site actions exposed to the network (and via WebMCP where supported): website_search_directory, website_get_api_details, website_call_public_api (allowlisted GET only, visitor-approved), website_analyze_json. A public MCP facade is honestly marked unavailable in agent-mcp.json because static hosting provides no server.
